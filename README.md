# Форма для леденцов

Лендинг с каталогом товара, информационными страницами и интерфейсным прототипом формы заказа.

## Требования

- Node.js `>=22.13.0`
- npm

## Запуск

```bash
npm ci
npm run dev
```

Локальный сайт будет доступен по адресу `http://localhost:3000`.

## Production-проверка

```bash
npm run build
npm start
```

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск dev-сервера Next.js |
| `npm run build` | Production-сборка |
| `npm start` | Локальный просмотр статического `out/` через `serve` |
| `npm run lint` | Проверка ESLint |
| `make clean` | Удаление зависимостей и генерируемых файлов |

Проект работает как обычное приложение Next.js. Cloudflare, Wrangler, D1, R2, Drizzle и серверное хранилище для лендинга не используются.

## Структура

- `src/app/` — маршруты Next.js, layout, стили и форма заказа;
- `src/components/` — переиспользуемые React-компоненты и UI-библиотека;
- `src/hooks/` — React hooks;
- `src/lib/` — общие утилиты;
- `src/app/styles/` — базовые стили приложения и локальная лицензия shadcn;
- `public/` — изображения и другие статические файлы;
- корневые конфигурации — `package.json`, `tsconfig.json`, `next.config.ts`, `eslint.config.mjs`.

Форма заказа пока является интерфейсным прототипом: отправка заказа, оплата и API доставки не подключены.
